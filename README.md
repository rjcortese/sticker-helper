# sticker-helper
This is a tool to help create sticker packs for Signal (and maybe other messengers too).

Usage:
1. Make a new directory to hold the sticker images.
2. Put the zip file that contains the images in the directory.
3. Run this script like:
```
poetry run python sticker_helper.py zipfile
```
4. Run signal desktop and go through the menues to create a new sticker pack from the output images.
